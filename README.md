**Smart India Hackathon 2026 (SIH 2026)**

- **Problem Title**: Strengthening Market Linkages & Price Discovery for Farmers  
- **Theme**: Agriculture, FoodTech & Rural Development  
- **Category**: Software  
- **Team**: Code Crusaders  

---

## 🌾 The Problem
Smallholder farmers suffer from **unfair farm-gate price realization** and **exploitative middleman cartels**, exacerbated by **complex, text-heavy digital interfaces** and **cost-prohibitive, fragmented rural transport** with **insecure cash settlements**.

---


## 💻 Tech Stack (As Specified in PPT Slide 4)
- **Frontend**: React.js 19, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti, Web Speech API (PWA & 2G/3G Ready).
- **Backend**: Node.js & Express.js REST API Gateway.
- **AI & Analytics**:
  - Bhashini Vernacular NLP & Dialect Parser
  - YOLOv8 Edge Vision Simulation
  - Net-Profit Mathematical Optimization Engine
